# Smart Road Incident & Emergency Optimization System

Prototype لاكتشاف الحوادث من فيديو + تقدير الشدة + توجيه إسعاف محسن + Dashboard (Streamlit).

## تشغيل محلي
1. python -m venv .venv
2. source .venv/bin/activate     # على Windows: .venv\Scripts\activate
3. pip install -r requirements.txt
4. streamlit run app/Home.py
